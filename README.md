# House of Monakshi OS

Founder-operated sourcing, product qualification and launch command centre for House of Monakshi.

Start here: README_MONAKSHI_OS.md

## Quick start

1. Create a Python virtual environment.
2. Install requirements.txt.
3. Run: streamlit run app.py
4. Import your private Monakshi state JSON from the Command Centre tab.

Important: this repository is public. Real supplier terms, customer data, credentials and private contracts belong only in the local/private state, never in Git.
